# Regular Expressions

This repository contains solutions for the **Regular Expressions** project as part of the ALU Software Engineering curriculum.

## Requirements
- All files are interpreted on Ubuntu 20.04 LTS.
- All Ruby scripts start with `#!/usr/bin/env ruby`.
- All files end with a newline and are executable.

## Tasks Summary

| Task | File | Description |
|---|---|---|
| 0 | `0-simply_match_school.rb` | Matches the literal string `School` |
| 1 | `1-repetition_token_0.rb` | Matches `hbttn`, `hbtttn`, `hbttttn`, `hbtttttn` |
| 2 | `2-repetition_token_1.rb` | Matches `hbn` and `hbtn` |
| 3 | `3-repetition_token_2.rb` | Matches `hbtn`, `hbttn`, `hbtttn`, etc. |
| 4 | `4-repetition_token_3.rb` | Matches `hbn`, `hbtn`, `hbttn`, etc. without square brackets |
| 5 | `5-beginning_and_end.rb` | Matches strings starting with `h` and ending with `n` with 1 char in between |
| 6 | `6-phone_number.rb` | Matches a 10-digit phone number |
| 7 | `7-OMG_WHY_ARE_YOU_SHOUTING.rb` | Extracts capital letters only |
| 8 | `8-textme.rb` | Parses SMS transaction log details `[SENDER],[RECEIVER],[FLAGS]` |
